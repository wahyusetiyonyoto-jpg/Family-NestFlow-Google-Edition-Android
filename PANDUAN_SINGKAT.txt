SiRinci V1.0 Google Only

1. Run GitHub Actions build awal.
2. Download artifact dan buka google-oauth-signing.txt.
3. Buat OAuth Client Android di Google Cloud:
   package com.sirinci.app + SHA-1 dari artifact.
4. Buat OAuth Client Web pada project Google Cloud yang sama.
5. GitHub Settings > Secrets and variables > Actions > Variables.
6. Buat GOOGLE_WEB_CLIENT_ID berisi Web Client ID.
7. Run workflow kembali.
8. Download SiRinci-V1.0-Google-Only-APK.
9. Install APK.
10. Saat pertama dibuka, pilih Gmail lalu langsung masuk dashboard.

Supabase Auth, Firebase Auth, dan Apps Script tidak digunakan.
